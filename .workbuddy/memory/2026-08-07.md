## 项目经验（踩坑记录）

- `articles` 目录是指向 `./site/content/posts` 的符号链接（mode 120000 已入库）。**git add 不能走 `articles/...` 路径，会报 "beyond a symbolic link"，必须用 `site/content/posts/...` 真实路径提交。**
- 文章惯例：`site/content/posts/YYYY-MM-DD-slug/index.md`，frontmatter 含 title/date/summary/tags；旧文用 `source: wechat` 字段（从公众号归档的），新写文章不带此字段。
- Git 流程：main 分支直接 commit + push origin main，不建分支不开 PR（AGENTS.md 规定）。
