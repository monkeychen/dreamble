# StockFunnel · 指数择时 + 强势股筛选

两套工具，主次分明：

1. **指数趋势择时（主策略，可实盘）**：沪深300 + 创业板指双指数 MA50 开关，ETF 执行。回测年化 +7.8%、最大回撤 -15.7%（同期沪深300持有：年化 +2.6%、回撤 -29.7%）
2. **强势股筛选（观察工具，不推荐实盘）**：相对强度 + 平台突破。2026-09 实战化审计后净超额≈0，保留作市场观察和研究基线

数据源为 [baostock](http://baostock.com)（免费、无需注册），前复权日线，全市场约 5400 只 + 7 个指数，2022-06 起。

## 每日工作流（尾盘/晚间 1 分钟）

```bash
# launchd 每天 19:00 自动跑 daily_run.sh（update → timing → screen），
# 早上或盘中只需要看结果：
cat output/daily_timing.txt
```

- **无翻转**（绝大多数日子）：不用任何操作
- **翻转日**：次日开盘买卖对应 ETF（各 50% 仓位），1 分钟完成
- **临界预警**（偏离 MA50 < 2%）：近日可能翻转，留意明日信号

手动执行：

```bash
./stockfunnel update      # 增量更新数据（晚上跑）
./stockfunnel timing      # 今日择时信号
./stockfunnel screen      # 选股观察（可选）
```

## 指数择时（主策略）

### 规则

- 标的：沪深300ETF + 创业板ETF（或对应指数基金），各 50%
- 开关：指数收盘 > MA50 → 持有该半边；收盘 < MA50 → 该半边转现金
- 信号口径：昨日收盘定今日仓位（与回测一致），翻转日次日开盘执行
- 切换成本按往返 0.1% 计（ETF 佣金+冲击）

### 命令

```bash
./stockfunnel timing                # 今日信号面板 + 操作指引
./stockfunnel timing --backtest     # 附全历史回测统计
./stockfunnel timing --ma 60        # 敏感性检查用（勿用于实盘微调）
```

信号历史写入 `output/timing_log.csv`（date, code, close, ma, signal, distance_pct），用于事后对账：信号翻转日 vs 你实际操作日。

### 验证结论（2022-06 ~ 2026-09，含成本）

| 指数 | 择时总收益 | 择时回撤 | 持有总收益 | 持有回撤 | 切换次数 |
|---|---|---|---|---|---|
| 沪深300 MA50 | +25.8% | -12.6% | +11.4% | -29.7% | 52 |
| 创业板指 MA50 | +47.6% | -26.5% | +35.3% | -46.3% | 68 |
| **50/50 组合** | **+37.7%（年化+7.8%）** | **-15.7%** | — | — | — |

年度分解：2022 -5.6% / 2023 -4.7% / 2024 +22.9% / 2025 +26.0% / 2026YTD -1.1%

**预期管理（重要）**：
- 它的本质是崩盘保险：熊市/转折年大胜（2023 沪深300少亏10.7pp），单边牛市跑输持有（2025 落后3.7-11pp，进场滞后是天性）
- MA40-60 是参数平台（16个指数×均线组合中11个正收益，回撤全部低于持有），MA20 被切换磨损，MA80+ 衰减——**不要微调参数**
- 样本 4.3 年、一轮牛熊，属于样本内验证；上线后用 timing_log.csv 持续对账

### 为什么不是选股（2026-09 研究记录）

在全市场 4.3 年日线数据上系统淘汰过一轮，全部含成本、T+1、可成交性约束：

| 方向 | 结果 | 死因 |
|---|---|---|
| 动量突破选股（本工具原策略） | ❌ | 净超额≈0，5年中仅2年为正，参数刀尖 |
| 尾盘日频战法（1天持有） | ❌ | 六类条件全部低于 0.3% 成本线；隔夜溢价只在涨>8%档存在（打板领域，日线无法诚实回测） |
| 小市值+20日反转 | ❌ | 超额锁在成交额<1亿的微盘股（不可交易）；组合模拟年化 11.8% ≈ 中证1000持有 12.4% |
| 周频指数动量轮动 | ❌ | -5%，切换过频被噪声绞死 |
| **MA50 指数趋势择时** | ✅ | 参数高原 + 回撤减半 + 熊市保护 |

个股层面在日线数据 + 散户成本结构下没有可交易的净alpha；指数层面的时序趋势有效。这是数据给的结论，不是偏好。

## 强势股筛选（观察工具）

从 5000 只 A 股里筛「刚冒头、还没加速」的强势股：120日RS前25% + 20日平台缩量 + 放量突破 + 均线多头 + 成交额≥2亿，分市场大盘过滤（主板→沪深300，创业板/科创板→创业板指）。

**审计后实测**（644信号，含成本/T+1/可成交性）：10日净超额 +0.00%，纪律单笔净 +0.26%、胜率 28.6%，组合年化 +5.9% 且满仓错过375次。**不建议实盘**，保留价值：市场情绪观察、研究基线、track 对账基础设施。

### 命令一览

```
./stockfunnel <子命令> [选项]
```

### `info` — 数据状态概览

```bash
./stockfunnel info
```

显示各市场股票数、日期范围、最近信号（读缓存，秒级返回）。

### `update` / `rebuild` — 数据维护

```bash
./stockfunnel update              # 增量更新全市场（几秒到几分钟）
./stockfunnel update -m star      # 只更新科创板
./stockfunnel rebuild -y          # 全量重建（30-60分钟，支持断点续传）
```

- 每只股票从自己的最后日期起增量拉取，失败自动补齐
- 更新前用多只大票探针确认数据源已发布当日数据，未发布快速返回
- `-m` 只限制下载/统计范围；`daily.parquet` 始终全市场合并
- 科创板股票池含退市股（消除幸存者偏差）

### `screen` — 强势股筛选

```bash
./stockfunnel screen              # 最近 5 天全市场
./stockfunnel screen -m cyb --days 10
```

输出候选股 + 双大盘开关状态（主板✓/✗ 成长✓/✗）。

### `look` — 单只股票查询

```bash
./stockfunnel look 600519                # 最近 20 天
./stockfunnel look 688981 --rs 120       # 加 RS 排名
./stockfunnel look 000001 --ma 5,13,21,55
```

### `backtest` — 选股回测（实盘口径）

```bash
./stockfunnel backtest                  # 全市场
./stockfunnel backtest --gap-max 3      # 次日高开>3%放弃
./stockfunnel backtest --positions 3    # 组合模拟3槽位
./stockfunnel backtest --no-cost        # 关闭成本（对比研究）
./stockfunnel backtest --json
```

口径：T+1、次日停牌/一字板/高开>4%不可成交、佣金万2.5×2+印花税万5+滑点0.1%×2（往返0.3%）、基准窗口对齐、槽位制组合模拟。

### `validate` — 稳定性与参数敏感性

```bash
./stockfunnel validate
```

年度稳定性 + 12 组单参数扰动，回答「是规律还是拟合噪音」。

### `track` — 选股实盘对账

```bash
./stockfunnel track               # 维护 output/trade_log.csv
```

信号登记 → 自动回填次日行情 → 手填 `fill_price` 实际成交价 → 监控回测假设与真实执行的偏差。

## 目录结构

```text
stockfunnel/
├── stockfunnel          # 统一入口
├── cli.py               # 命令行调度
├── data_layer.py        # 数据层：下载 / 更新 / 合并 / 加载
├── timing.py            # 主策略：指数 MA50 择时 + 信号日志 + 回测
├── strategy.py          # 选股策略层：筛选 + 回测 + 验证 + 对账
├── query.py             # 查询层：单只股票行情
├── daily_run.sh         # launchd 每日任务（19:00）
├── data/                # 本地数据缓存（git 忽略）
└── output/
    ├── daily_timing.txt # 每日择时信号（主产物）
    ├── daily_screen.txt # 每日选股观察
    ├── timing_log.csv   # 择时信号历史（对账用）
    ├── trade_log.csv    # 选股对账表
    └── daily_run.log    # 运行日志
```

## 风险提示

- 回测基于历史数据，不代表未来表现；择时样本仅一轮牛熊
- 趋势择时在单边牛市必然跑输持有，接受这一点再上线
- 策略有衰减风险：定期用 `timing --backtest` 复验，用信号日志对账
- 本工具仅用于策略研究，不构成投资建议
