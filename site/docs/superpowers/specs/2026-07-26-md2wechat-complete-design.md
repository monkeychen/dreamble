# md2wechat 完整版设计规范

日期：2026-07-26

## 1. 目标

把 `/tools/` 中的 md2wechat 从轻量转换器升级为可独立完成公众号文章排版的浏览器工具。用户应能从 Markdown 文件或空白稿开始写作，完成格式处理、主题选择、预览和导出，最后一次复制到微信公众号编辑器。

“类似参考站点”指覆盖同一条完整用户任务链，而不是复制其界面、文案或主题 CSS。

## 2. 完整任务链

1. 新建、导入 `.md` / `.txt` 或恢复本地草稿。
2. 用工具栏或快捷键插入标题、粗体、斜体、删除线、行内代码、代码块、链接、图片、引用、列表、表格和分割线。
3. 实时预览常用 Markdown、GFM 表格/任务列表，以及脚注、目录、数学公式和注音。
4. 分别选择正文主题和代码主题；按需调整主题色、正文字号、行高、段距和字体。
5. 在双栏、仅编辑、仅预览和全屏模式之间切换，长文可同步滚动。
6. 复制微信公众号富文本，或导出 Markdown、完整 HTML、打印/PDF。
7. 刷新页面后恢复草稿、主题、样式参数和视图偏好。

## 3. 主题体系

- 至少 12 套内置正文主题，覆盖杂志、经典、便签、商务、极简及多种色彩倾向。
- 主题差异必须落实到标题、引用、列表、表格、分割线和行内强调，不只替换颜色。
- 至少 7 套代码主题，与正文主题独立切换。
- 提供可视化样式调整；调整后作为当前自定义配置保存，但不覆盖内置主题定义。
- 所有复制结果必须使用内联样式，不能依赖本站 CSS、class 或外部字体文件。

## 4. 文件与输出

- 导入只读取用户主动选择的 UTF-8 `.md` / `.markdown` / `.txt`。
- 本地图片转为浏览器内嵌数据；限制单图大小并在超限时给出可行动提示。
- Markdown 导出保留原文；HTML 导出包含当前主题的完整排版；PDF 使用浏览器打印能力。
- 富文本剪贴板同时提供 `text/html` 和 `text/plain`。
- 根标签和所有属性必须由 DOM 序列化，不能拼接未转义 HTML。

## 5. 安全与边界

- Markdown 生成的 HTML 必须经 DOMPurify 清理。
- 禁止脚本、iframe、表单、事件属性和不受控样式进入预览或剪贴板。
- 不新增服务器、数据库、登录、公众号密钥或第三方图床 Token。
- 不实现公众号草稿箱直传；其账号权限和凭据边界应作为独立项目设计。

## 6. 交互与响应式

- 桌面默认双栏；手机默认单面板，通过“编辑/预览”一步切换。
- 所有核心操作有文字或可访问名称，支持键盘焦点。
- 工具栏允许横向滚动或折行，不能造成整页横向溢出。
- 状态提示说明结果和下一步，例如“已复制，可粘贴到公众号”，不能只显示“成功”。

## 7. 验收标准

- 自动化测试覆盖主题注册、设置归一化、文本格式命令、扩展语法预处理、外链脚注和导出文件名。
- `npm run verify` 全部通过。
- 真实浏览器验证桌面与 375px 手机布局、导入导出、格式工具、12 套正文主题、7 套代码主题、样式调整、草稿恢复、视图切换和同步滚动。
- 实际执行富文本复制并粘贴到可编辑区域，确认标题、列表、引用、表格、代码、脚注和公式结构存在，且没有原始根标签文本。
