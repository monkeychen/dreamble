# 作者档案（默认空白，可选填）

这个文件解决一个问题：**文章里的"我"是谁**。

样本作者有一整套自己的锚点（哪年入市、哪个城市、什么学历、什么账户结构），读者看多了会觉得"认识这个人"。那些锚点属于他，不能搬到别人的文章里。所以这个 skill 的默认行为是：**不写任何具体生平细节**，只保留具身视角（看盘的动作、街上看到的场景、听来的一句话）。

不填这个文件完全没问题——多数文章不需要个人锚点也能写好。填了的话，文章可以带上你自己的履历，且每篇保持一致。

## 怎么用

- **空白状态（现在）**：写作时按 SKILL.md 的"个人身份边界"执行，不出现年份、金额、城市、学历、亲属等可核验的个人事实。
- **填写之后**：文章可以使用下面登记的锚点，跨文章数值必须一致（同一个锚点这篇写"2019 年"、下篇写"2020 年"，比不写更糟）。
- **随时补录**：用户在聊天里提到自己的真实经历（"我 2019 年才开户"），写作时可以直接用，事后补一行到这里。

只填你愿意公开、且**将来还会重复提**的信息。一次性的、不打算再提的经历，直接写进那篇文章就行，不用登记。

## 一、基本锚点

| 锚点 | 你的内容 | 备注 |
|---|---|---|
| 入市时间 / 从业起点 | | 例："2019 年开的户"。写年份就行，不必写月份 |
| 起步本金量级 | | 只写量级（"几万块起步"），不必写精确数字 |
| 常驻城市 | | 影响房价、物价、生活场景类素材 |
| 职业背景 | | 影响你能拿什么行业经验做类比 |
| 账户结构 | | 例："一个主账户 + 两个打新小号"。不写余额 |
| 公众号/发布场景 | | 有没有打赏、有没有固定栏目名、更新频率 |

**关于打赏**：只有这一栏填了"有打赏"，文章才可以用"鞠躬。""谢赏！"这类收尾。否则一律用"就这些。"

## 二、可复用的生活素材

写社会观察类文章时的切入素材。登记的是**你真实有过**的经历，且不介意反复提。

| 类型 | 你的素材 |
|---|---|
| 一次印象深的买卖决策 | |
| 和陌生人的对话场景（司机/邻居/店主） | |
| 一段职业经历里的教训 | |
| 一个长期观察的对象（某个行业/某只票/某个小区） | |

没填的类型，写作时用关系类型泛指（"一个开网约车的"、"一个做实业的朋友"），不要编造具体人物。

## 三、判断口径（比履历更重要）

这部分不涉及隐私，但对"老朋友感"的贡献比履历大得多。建议填。

| 项目 | 你的口径 |
|---|---|
| 风险偏好 | 例：宁可错过不要做错 / 敢在恐慌里加仓 |
| 长期看多还是看空的领域 | |
| 明确不碰的东西 | 例：不碰杠杆、不碰概念股 |
| 判断错了怎么处理 | 例：下一篇开头认一句 |

跨文章保持这套口径一致，读者就会形成"这个人一贯怎么想"的印象——这才是老朋友感的真正来源，比"我 2014 年入市"有效得多，而且不需要暴露任何个人信息。
