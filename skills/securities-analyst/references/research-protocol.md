# 研究核验协议

## 研究截止时间

- 每次研究先记录 `as_of`，所有行情、财报、公告、预测和结论都受该时间边界约束。
- 历史回放不得使用 `as_of` 之后的信息，包括后来修订的数据、后见之明和事后形成的机构观点。
- 每个关键结论都要能追溯到证据、假设或明确标注的推断。

## 信息源优先级

优先顺序如下：

1. 公司公告、交易所文件、监管文件、官方统计、央行/财政部门发布、公司投资者关系资料。
2. 交易所或可靠行情数据源，用于股价、成交额、市值、估值和流动性。
3. 电话会纪要、管理层演示材料、招股书、债券募集说明书、股东通函。
4. 权威财经媒体和数据服务商。
5. 券商研报、投行观点、一致预期和第三方数据库。
6. 社交媒体、市场传闻、论坛讨论只能作为情绪证据，不能当作事实。

## 时效规则

- 相关市场已收盘时，使用当天收盘数据。
- 市场交易中时，只能使用带明确时间戳的盘中数据。
- 如果无法取得实时数据，可以使用前一交易日收盘数据，但必须说明。
- 财报和公告必须识别最新年报、中报、季报、业绩预告、回购、分红、并购、减持、股权激励、重大合同等。
- 涉及政策和监管时，必须优先核验官方或高度权威来源，再做判断。

## 数据完整性

- 每个关键数字都要标注来源或来源类型。
- 如果不同来源数据冲突，说明差异，并优先采用原始公告或交易所数据。
- 不得编造财务数据、预测、机构观点、传闻、目标价或技术位。
- 区分历史指标和前瞻预测。预测年份必须写清楚，例如 `2026E PE`。
- 如果缺少机构一致预期，根据历史经营、最新披露、行业数据和可比公司建立明确的本研究情景，不要给伪精确数值，也不能因此跳过预测和估值。
- 声称某项公开数据“无法取得”前，应检查原始公告、交易所、公司投资者关系资料及至少一个可靠市场数据源，并在底稿中记录查找范围。

## 证据账本

深度研究用统一字段记录关键证据：

- `claim`：该证据支持或反对什么判断。
- `source`：来源名称、链接或本地文件。
- `as_of`：数据日期或披露日期。
- `evidence_type`：`fact`、`market_data`、`management_claim`、`consensus` 或 `inference`。
- `confidence`：高、中、低。
- `impact`：对经营预测、估值、催化剂或风险的影响。
- `open_question`：尚未解决的问题。

管理层口径不能自动升级为事实，一致预期不能自动升级为正确预测。二手来源引用原始披露时，尽量回到原始披露核验。

## 结论强度门槛

- 关键行情、股本或财报口径未核验：不输出精确目标价。
- 关键业务缺少分部数据：降低预测精度，并说明估值折价或范围。
- 可比公司不可比：不用“行业平均倍数”制造精确结论。
- 原始披露与二手数据冲突：优先重算；无法消除时保留两个口径并说明影响。
- 最强反方证据未处理：不得给高置信度结论。
- 经营假设、股本、汇率或资本结构变化后未重新计算下游模型：不得沿用旧目标价。
- 点名个股且用户未要求简答时，公司业务与产业链、相对行情、历史财务、同业和估值任一部分尚未完成：不得把事件摘要包装成完整个股研究。

## 分析纪律

按“事实到推论”的链条表达：

1. 事实：已经核验了什么。
2. 解读：这对业绩、估值、流动性或情绪意味着什么。
3. 决策影响：对应什么操作或跟踪项。
4. 证伪条件：什么情况会推翻当前判断。

对热门概念，必须判断真实关联度：

- `强相关`：收入、利润、订单或客户暴露有实质贡献且可核验。
- `中相关`：有真实业务关联，但贡献还小或处于早期。
- `弱相关`：只是间接产业链映射或叙事映射。
- `蹭热点`：市场故事缺少可核验的业务支撑。
