# 多 Agent 研究与模型路由

仅在任务是深度个股研究、产业链复杂、需要处理大量披露或需要独立反证时启用多 Agent。简单问答、概念解释和单一财报事实核验直接由主 Agent 完成。

## 路由原则

1. 先按能力档位路由，再映射到当前可用的 OpenAI 模型，避免模型名称更新后整套 Skill 失效。
2. 数据抓取、表格合并、公式计算和格式转换优先使用确定性工具，不用 Agent 模拟计算器。
3. 需要业务理解、预测、估值、冲突处理和反方论证时才提高模型能力或推理等级。
4. 子 Agent 只提交证据、假设和模块判断；最终投资命题和结论由主 Agent 统一负责。
5. 不因任务被拆成多个 Agent 就默认全部使用最高配置。

## 能力档位

| 档位 | 适用任务 | 当前 OpenAI 映射 |
| --- | --- | --- |
| `frontier` | 编排、复杂预测、估值、冲突处理、最终综合 | GPT-5.6 Sol |
| `balanced` | 基本面、行业、竞争、普通财务研究和报告整合 | GPT-5.6 Terra |
| `fast` | 来源检索、公告摘录、字段提取和批量整理 | GPT-5.6 Luna |

以上映射以 2026-08-25 的 OpenAI 模型分层为基线。执行环境已有更新模型时，按同等能力档位替换；不要仅凭版本号推断能力。若任务通过 API 运行，使用当前官方模型文档核验模型 ID 和支持的推理参数。

## 默认角色配置

| 角色 | 任务边界 | 能力档位 | `reasoning.effort` | `reasoning.mode` |
| --- | --- | --- | --- | --- |
| 主编排 Agent | 研究任务卡、拆分、证据冲突、停止条件和最终结论 | `frontier` | `high` | `standard` |
| 资料与公告 Agent | 原始披露、行情、时间戳、口径和证据账本 | `fast` | `low` 或 `medium` | `standard` |
| 业务与行业 Agent | 业务经济、价值链、竞争优势、周期和资本开支 | `balanced` | `high` | `standard` |
| 财务与预测 Agent | 财务取证、关键驱动、三情景预测和敏感变量 | `frontier` | `high` | `standard` |
| 估值与预期 Agent | 估值交叉验证、反向估值和市场隐含预期 | `frontier` | `high` | `standard` |
| 风险反证 Agent | 最强反方证据、预演失败、证伪条件和遗漏检查 | `frontier` | `xhigh` | `standard` |

`max` 不作为默认 `reasoning.effort`，Pro 也不作为默认 `reasoning.mode`。二者是独立参数，不是同一档位。只有研究价值高、输入复杂、评测证明相对 `xhigh + standard` 有明显质量提升时，才考虑 `max`、`pro` 或两者组合用于一次独立终审。

## 主 Agent 编排流程

1. 创建研究任务卡，确定 ticker、交易所、`as_of`、决策问题、周期和完成门槛。
2. 判断哪些任务可独立并行，避免多个 Agent 重复抓取同一材料。
3. 为每个子任务写明输入边界、必查来源、输出字段和停止条件。
4. 收集证据账本，先统一时期、币种、会计口径、股本和预测假设。
5. 将经营驱动传递给预测，将预测传递给估值；上游假设变化必须重新计算下游结论。
6. 风险反证 Agent 在看到完整初步命题后独立审查，不提前获得预设的正确答案。
7. 主 Agent 处理冲突、调整置信度并形成最终研究结论。

不要用多数投票解决研究冲突。三个 Agent 同意同一结论，不代表结论正确；原始披露、口径一致性和可证伪逻辑优先。

## 运行环境降级

Skill 只能提出路由要求，不能保证运行环境支持逐子 Agent 指定模型和推理等级。

- 环境支持逐 Agent 配置：使用上表，并记录每个角色的实际模型和推理等级。
- 只支持统一模型：所有角色继承主 Agent 配置，通过独立上下文、任务边界和证据结构保持角色分离。
- 不支持 Agent 委派：主 Agent 按相同顺序分阶段完成，每阶段落入证据账本后再进入下一阶段。
- 模型或推理等级不可确认：报告“继承/未知”，不得声称使用了指定配置。

## 完成报告

深度研究结束后简要报告：

- 实际启用的研究角色。
- 每个角色实际 `model_id`、`reasoning.effort` 和 `reasoning.mode`，无法确认时明确标注。
- 数据截止时间和主要来源范围。
- 未解决的证据冲突和降级项。
- 是否执行独立反方审查。

主 Agent 在汇总子 Agent 结果后，直接生成并自检普通投资者可读、可作为公众号正文使用的最终 Markdown 报告；不设置额外角色来补研究或重写结论，发布环节只做排版和渠道适配。
