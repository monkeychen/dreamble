# 个股深度研究框架

这是一套从证据到投资判断的闭环，不是固定篇幅的报告模板。分析目标是回答四个问题：这家公司靠什么创造价值，未来由什么驱动，当前价格隐含了什么预期，什么情况会让判断失效。研究过程可以使用专业模型，最终正文必须让不了解公司的普通投资者直接读懂。

## 一、研究任务卡

研究开始前先确定：

- 证券名称、ticker、交易所和主要上市地。
- 上市证券主数据：上市币种、报价单位、股份类别、稀释后总股本、每份 ADR/存托凭证对应普通股数量，以及适用汇率时点。
- 数据截止时间，以及使用收盘、盘中还是历史回放口径。
- 决策问题：首次覆盖、持仓复核、财报点评、事件驱动、估值比较或交易计划。
- 观察周期：短期事件、中期业绩或长期配置。
- 用户未说明风险偏好时采用保守假设，不据此编造个性化仓位。

只有同名证券无法消歧、研究时点不明确且会改变结论、或缺少完成任务的关键文件时才追问。其他信息通过研究补齐。

### 默认深度

- 用户只要点名股票并说“分析一下”“为什么涨跌”“还能不能买”或询问某次公告、财报、减持和回购，默认执行完整个股研究。
- 事件驱动问题应把事件放在文章主线上，但仍要交代公司业务、产业链位置、基本面、估值和交易位置；否则无法判断事件究竟重要不重要。
- 只有用户明确要求简短回答、只解释事件，或询问基础概念时，才使用简版。简版也必须包含当前行情、事件事实、影响路径和判断边界。

## 二、先确定核心判断，再展开研究

在内部底稿中先回答以下问题，用来约束后续研究：

| 字段 | 要回答的问题 |
| --- | --- |
| 现在怎么看 | 当前价格下是低估、合理、高估，还是证据不足 |
| 最重要的原因 | 未来 1-3 个最重要的价值驱动是什么 |
| 市场在相信什么 | 主流叙事和当前价格已经计入什么 |
| 可能看错的地方 | 哪个关键变量可能与市场预期不同 |
| 为什么现在值得讨论 | 催化剂、拐点或估值窗口为何在当前出现 |
| 对价格意味着什么 | 判断兑现或失败分别对应什么价值区间 |
| 什么情况下改判断 | 哪些可观测事实出现后必须降级或撤销结论 |
| 最大未知数 | 哪个数据缺口最可能改变结果 |

这张表只用于研究过程，默认不以“投资命题卡”形式出现在最终文章。研究过程中若证据不支持，必须修改判断并保留冲突说明。

## 三、完成股票分类

读取 [stock-classification.md](stock-classification.md)，完成：

1. 基本面主要类型和次要类型。
2. 生命周期与周期位置。
3. 当前市场交易属性。
4. 最重要的 3-5 个经营指标。
5. 不适用的指标和估值方法。

分类决定后续研究重点。不得为了套用熟悉的 PE、DCF 或技术指标而忽略公司类型。

### 个股研究证据下限

完整个股研究必须取得并分析以下证据；公开数据确实不存在时，逐项说明缺口及影响：

1. 最新股价、涨跌幅、市值、成交额或流动性、近 1 个月/3 个月/1 年表现，以及与主要指数、行业和可比公司的相对表现。
2. 公司主营业务、收入和利润结构、核心产品、客户与地区、产业链上下游、公司所处环节及议价能力。
3. 最近 3-5 年和最新一期的收入、利润、利润率、现金流、回报率、负债和股本变化；指标按公司类型取舍。
4. 原则上至少 3 家真正可比公司的业务差异、增长、盈利质量和估值。找不到 3 家时，不得用不相干公司凑数，应说明原因。
5. 未来 1-2 年的经营驱动、盈利情景和估值。机构一致预期只是参考，不是完成预测的前提。
6. 近期涨跌的公司事件、行业板块、市场风格、资金和筹码因素，并用时间线或相对收益区分主因与巧合。

## 四、理解业务经济，而不是复述公司简介

### 4.1 业务与价值链

- 按产品、客户、地区和渠道拆分收入、利润、资产与资本开支。
- 说明客户为什么付费、公司如何定价、成本由什么决定、现金如何回收。
- 画出关键价值链：供应商、公司、渠道、客户、替代品和监管者。
- 区分现有盈利业务、成长业务和尚未验证的新业务期权。

### 4.2 行业结构与竞争优势

- 判断市场空间、渗透率、需求弹性、供给约束、库存和资本开支周期。
- 比较市场份额、成本曲线、技术、品牌、渠道、网络效应、转换成本和监管牌照。
- 检查所谓壁垒是否转化为稳定或改善的 ROIC、利润率、现金流和客户留存。
- 说明竞争优势的来源、持续时间和最可能被破坏的路径。

### 4.3 管理层、治理与资本配置

- 检查管理层历史承诺与实际兑现、激励机制、关联交易和少数股东利益。
- 评估资本开支、并购、分红、回购、举债和股权融资是否创造每股价值。
- 区分公司增长与每股价值增长，识别稀释、低回报扩张和帝国式并购。

## 五、做财务取证和盈利质量分析

至少覆盖 3-5 年历史和最近一期，并按公司类型选择更长周期：

1. 利润表：收入量价、毛利率、费用率、经营利润率、税率和一次性项目。
2. 资产负债表：应收、存货、合同负债、固定资产、商誉、净负债和表外义务。
3. 现金流量表：经营现金流、资本开支、自由现金流、融资和股东回报。
4. 回报质量：ROIC、ROIIC、ROE、现金利润匹配和再投资效率。
5. 每股质量：股本变化、股权激励、可转债、回购和潜在稀释。

必须检查：

- 净利润与经营现金流长期背离。
- 应收、存货或合同资产增速持续快于收入。
- 毛利率改善是否来自会计口径、产品结构或真实经营效率。
- 资本化政策、折旧年限、减值、商誉、关联交易和非经常性损益。
- 非 GAAP、调整后利润与法定口径差异。
- 审计意见、内控缺陷、监管问询和管理层频繁变更。

若盈利质量存在重大红旗，先处理持续经营和资产负债表风险，再讨论增长和估值。

## 六、建立关键驱动模型和预测

预测不能直接外推历史增速。先建立 3-7 个关键经营驱动，再把驱动映射到三张表和自由现金流。

常见驱动关系：

```text
收入 = 销量或用户数 × 单价或 ARPU
毛利 = 收入 × 毛利率
经营利润 = 毛利 - 经营费用
NOPAT = EBIT × (1 - 现金税率)
自由现金流 = NOPAT + 折旧摊销 - 资本开支 - 营运资本增加
增长创造价值的必要条件：增量投入回报率持续高于资本成本
```

根据公司类型替换驱动：银行看资产规模、净息差、信用成本和资本约束；保险看新业务价值、投资收益和偿付能力；资源股看价格、产量、品位和成本；平台公司看用户、交易额、变现率和履约成本；研发型公司看管线成功概率、上市时间、峰值销售和融资需求。

至少给出悲观、中性、乐观三种情景。每种情景必须写清：

- 收入、利润率、再投资、现金流和资本结构的关键假设。
- 假设对应的行业、公司或管理层证据。
- 公司历史、同类公司和行业周期提供的基准概率，避免只采用管理层目标。
- 未来 1-3 年详细预测，以及估值需要时从高增长或异常周期逐步回归稳态的路径。
- 情景切换的可观测条件。

没有可靠一致预期时，必须根据历史经营、最新披露、行业数据和可比公司自行建立买方情景，并明确标为本研究假设。只有关键行情、股本、财报或业务数据客观无法取得，导致数值模型没有合理锚点时，情景才可以定性；不得为了满足形式制造数字，但也不得把“没有一致预期”当成放弃预测和估值的理由。无法给精确盈利和目标价时，改用条件化区间、单位经济、资产价值或里程碑估值。

涉及数值预测、DCF、敏感性、情景价值或目标价时，必须使用代码或表格模型计算，不在自然语言中心算。上游经营假设变化后必须重新计算利润、现金流、企业价值、股权价值和每股价值。可使用 [equity_scenario_model.py](../scripts/equity_scenario_model.py) 校验情景概率、企业价值到股权价值、跨币种/ADR 每股价值和年化总回报。

## 七、估值必须形成交叉验证

估值步骤：

1. 根据股票分类选择主要估值方法，并解释为什么适用。
2. 数据允许时至少使用两种相互独立的方法，例如内在价值与可比估值。
3. 检查可比公司的业务、增长、利润率、资本结构和会计口径是否真的可比。
4. 对关键输入做敏感性分析，避免只给单点目标价。
5. 由企业价值桥接到股权价值和每股价值，明确净负债、少数股东、非经营资产和稀释股本。
6. 从公司股权价值桥接到实际上市证券价格：核对上市币种、报价单位、股份类别、A/H 股权利差异、ADR 换股比例和每份上市证券代表的普通股数量；跨币种目标价必须为每个情景设置目标日汇率假设，不能拿当前汇率冒充未来汇率。
7. 读取 [special-frameworks.md](special-frameworks.md)，完成反向估值和结论校验。

使用 DCF 时，详细预测期要覆盖主要经营变量向稳态收敛的过程；终值增长、稳态利润率、ROIC、再投资率和资本成本必须相互一致，并说明终值对总估值的贡献。终值增长率不得机械高于公司长期可持续的经济增长约束。

多种估值方法用于揭示假设风险，不得机械取平均。根据公司类型、数据质量和估值目的确定主方法，其他方法作为独立交叉检查。反向估值用于读取市场预期，不算独立的公允价值估算。

必须同时回答：

- 当前价格隐含怎样的收入增速、利润率、ROIC、市场份额、商品价格或成功概率。
- 这些隐含假设与公司历史、行业容量和可比公司的差距有多大。
- 市场是在低估公司，还是研究者只是使用了更乐观的假设。
- 悲观、中性、乐观价值区间分别是多少，当前价格对应怎样的风险收益比。

目标价必须能追溯到预测和估值假设，不得由主观涨幅倒推。

## 八、识别预期差与重估路径

好公司不等于好股票，正确预测也不等于有超额收益。必须区分：

- 已知事实。
- 管理层叙事。
- 市场一致预期或主流叙事。
- 当前价格隐含预期。
- 本研究的差异化判断。

预期差必须落到可验证变量，例如销量、价格、毛利率、订单、资本开支、现金流、份额或监管里程碑。不得把“市场没看懂”当作无需证据的结论。

说明重估需要什么催化剂、可能在什么时间窗口发生，以及没有催化剂时价值实现为何可能延迟。

## 九、建立反方论证和风险树

在最终结论前执行一次预演失败：假设 12-24 个月后投资结果显著低于预期，倒推最可能的原因。

至少覆盖：

- 命题错误：市场空间、竞争优势或管理能力判断错误。
- 预测错误：销量、价格、利润率、资本开支、现金流或融资需求偏差。
- 估值错误：可比选择、终值、资本成本或周期位置错误。
- 事件风险：监管、诉讼、治理、减持、解禁、汇率和流动性。
- 路径风险：长期判断正确但短期资金、技术和事件窗口造成大幅回撤。

列出支持命题的最强证据和反对命题的最强证据。风险必须绑定领先指标、触发阈值、对估值的影响和应对动作。

## 十、把研究转成可执行结论

分别回答：

1. 公司质量如何。
2. 当前价格是否有安全边际。
3. 当前是否存在预期差和催化剂。
4. 当前交易位置是否适合执行。

最终结论使用：买入、持有、减仓、卖出、观望、只适合交易、不适合配置，或“暂不支持明确操作结论”。同时给出：

- 适用周期和风险承受能力。
- 明确目标日期的悲观、中性、乐观价值区间。
- 数据支持时，给出有基准依据的情景权重；计算包含股息、回购或稀释和汇率影响的概率加权总股东回报及年化回报。权重缺少依据时改做敏感性，不伪造概率。
- 上行空间、下行空间、持有期和风险收益比。
- 数据与风险画像支持时，给出研究性的分批建仓、加减仓、止损或证伪规则；否则只列条件，不给仓位数字。
- 5-10 个跟踪变量及其更新频率。

没有用户风险画像时，仓位只给研究性区间和条件，不包装成个性化投顾建议。

## 十一、公众号可直接发布的输出契约

最终报告不是把内部研究模块依次贴出来。根据用户的问题组织叙事，默认采用以下自然结构：

1. **先说结论**：用一段话回答这是什么公司、这次为什么涨跌、当前贵不贵、现在适不适合买。
2. **这家公司到底靠什么赚钱**：讲清产品、客户、收入利润来源和产业链位置，让第一次接触公司的读者建立基本认识。
3. **行业位置决定了它能赚多久**：说明行业景气、供需或竞争格局，公司为何可能胜出，壁垒是否真的反映在利润和现金流中。
4. **财务数字是在变好，还是看起来很美**：用必要的历史表格和最新一期数据解释增长质量、现金流、负债和每股价值。
5. **最近股价为什么这样走**：把公司事件、板块、市场风格、资金与筹码按时间线拆开，并与指数和同行表现比较。
6. **现在的价格到底贵不贵**：展示可比估值、未来情景、主要估值方法和当前价格隐含预期，用普通语言解释计算含义。
7. **现在该怎么做**：区分公司是否值得长期跟踪与当前价格是否适合买入；给出适用周期、风险承受能力、目标区间或条件、加减仓与退出规则。
8. **我最可能错在哪里**：列出最强反面证据、判断改变条件和后续跟踪指标。

文章标题不必机械使用以上八个名称，可以根据事件和核心结论改成更自然的标题。数据表格、来源和风险提示保留；“投资命题卡”“股票类型诊断”“风险树”“证伪条件”等内部术语不直接作为读者可见标题。专业术语首次出现时顺手解释，不假设读者已有金融背景。

## 十二、多 Agent 研究兼容

运行环境支持委派时，读取 [multi-agent-routing.md](multi-agent-routing.md)，可以并行拆分为：资料与公告、业务与行业、财务与预测、估值与预期、风险反证五个研究任务。主 Agent 负责研究任务卡、证据去重、口径冲突、预测与估值一致性和最终结论。

子 Agent 应返回结构化证据和判断，不直接争夺最终结论：

```json
{
  "claim": "需要验证的判断",
  "evidence": "支持或反对证据",
  "source": "来源名称和链接或文件",
  "as_of": "数据或披露日期",
  "evidence_type": "fact|market_data|management_claim|consensus|inference",
  "confidence": "high|medium|low",
  "impact": "对预测、估值或风险的影响",
  "open_question": "仍未解决的问题"
}
```

多 Agent 不能用多数投票代替判断。出现冲突时回到原始披露、统一口径并说明仍无法消除的不确定性。若运行环境不能指定子 Agent 模型或推理等级，继承主 Agent 配置并如实报告，不声称执行了未生效的模型路由。

## 十三、完成门槛

满足以下条件才可给明确目标价和操作结论：

- 关键行情、财报和股本口径已核验。
- 公司业务、产业链位置和竞争格局已经讲清楚，核心判断能被经营驱动和证据支持。
- 最近 3-5 年和最新一期财务趋势已核验；阶段收益已经与指数、行业和可比公司比较。
- 原则上完成至少 3 家真正可比公司的分析，或明确说明为何不存在足够可比对象。
- 一个主要估值方法可用，且有提供独立经济锚的第二种估值校验，例如 DCF 对可比估值、NAV、重置成本或分部估值；重复同一模型、算术勾稽和反向估值都不算独立估值方法。
- 企业价值、股权价值、稀释股本、上市币种、汇率、ADR/股份比例和报价单位已完成勾稽。
