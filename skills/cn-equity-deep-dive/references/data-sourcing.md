# 数据可得性分档与取数编排

> 命令简写 `westock-data <cmd>` = `npx -y westock-data-skillhub@1.0.5 <cmd>`。参数细节见 westockdata 技能的 `references/commands.md`。

这份表解决的是**最致命的问题**：研究需要 100+ 个数字，但只有一部分能可靠拿到。分档决定了每个数字在报告里的地位——

- **A 类**：工具直取，可作为决策依据
- **B 类**：需抓公告/年报原文，拿到才可引用，拿不到标缺口
- **C 类**：只能定性或推断，必须标注口径与来源，**不得作为核心决策依据**
- **算**：由 A/B 类数据推导，报告中必须列出输入量与公式

---

## A 类 · 工具直取

### 第一轮（无依赖，全部并行发出）

| 研究需求 | 命令 | 要点 |
|---|---|---|
| 代码解析 | `search <名称>` | 默认仅搜股票；可转债 `--type bond`、板块 `--type sector`、指数 `--type index` |
| 价格 / 市值 / 历史序列 | `kline <code> --period day --limit 5` | **有延迟**，必须标注数据日期，勿称"现价"；复权加 `--fq qfq`；支持 `--start/--end` |
| 5 年三大报表 | `finance <code> --num 20` | 5 年×4 期；`--type income\|balance\|cashflow` 单表；港股同样支持 |
| 公司简况 | `profile <code>` | 股本、行业、主营 |
| 十大股东 / 股东户数 / 机构持仓 | `shareholder <code>` | 港股返回持股股东 + 机构持仓 |
| 分红 | `dividend list <code> --years 5` | 加 `--all` 含未实施方案 |
| 回购 | `buyback <code>` | A 股 / 港股；支持 `--start/--end` |
| 研报列表 | `report list <code> --limit 10` | 个股或行业代码均可；**拿 ID 后第二轮 detail** |
| 公告列表 | `notice list <code> --type 0 --limit 30` | type：0全部 1财务 2配股 3增发 4股权变动 5重大 6风险 7其他 |
| **股权质押** | `risk <code> --types pledge` | **A 股治理尽调核心，不要漏** |
| **限售解禁** | `risk <code> --types unlock` | 解禁规模与时间点 |
| 违规 / 处罚 / 诉讼等 | `risk <code>` | 8 类风险事件，全量跑一遍 |
| 北向持股 | `fund north-holding <code>` | A 股；支持板块裸码 |
| 南向持股 | `fund south-holding <code>` | 港股 |
| 资金流 | `fund flow <code>` | 跨市场须分开查 |
| 港股做空比例 | `fund short <code>` | **港股流动性/做空分析必备** |
| 大宗交易 | `fund block <code>` | |
| 融资融券 | `fund margin <code>` | |
| 筹码成本 | `chip <code>` | 仅沪深京 A 股，看获利盘/套牢盘 |
| 龙虎榜 | `lhb --type institution,hotmoney` | 仅 A 股 |
| 财报披露日历 | 财报披露日历命令 | **用于排催化剂时点** |
| 同业批量对比 | `finance <c1>,<c2>,<c3> --num 20` | 逗号批量，只调 1 次；`report list` / `fund flow` 同样支持 |
| 板块估值历史分位 | `sector valuation <板块码>` | **板块级，不是个股** |
| 行业财务 / 盈利预测 | `sector finance` / 行业未来盈利预测 | 申万口径 |
| 行业经营数据 | sector 相关命令 | 价格 / 产量 / 销量——**ASP 与产能量的一手锚** |
| 宏观 | `macro indicator cn_core --date <日期>` | 政策与宏观环境 |
| 可转债条款 | `bond detail <转债码> --terms` | 转股价 / 强赎 / 下修 / 回售全有 |
| 指数成份 | `index constituent <指数码>` | 判断是否在沪深港通、是否被指数纳入 |

### 第二轮（依赖第一轮返回的 ID）

| 需求 | 命令 | 依赖 |
|---|---|---|
| 研报全文 | `report detail <研报ID>` | 优先取最近 3–5 篇，用于一致预期、产能、市占率、单位经济 |
| 年报 / 问询回复全文 | `notice detail <公告ID>` | 沪深返回**纯文本**；港股 / 美股返回 **PDF URL**（需再取） |
| 关键公告（质押、解禁、减持、股权变动） | `notice detail <公告ID>` | 从 `notice list --type 4/5/6` 筛 |

## B 类 · 需抓原文，拿不到就标缺口

| 研究需求 | 路径 | 常见结果 |
|---|---|---|
| 审计意见 / 事务所 / 更换史 | 年报公告 → `notice detail` | 沪深纯文本可读到；港股 PDF 可能读不全 |
| 商誉明细与减值测试 | 年报附注 | 经常拿不到结构化数据 → 用 A 类商誉总额 + 减值史代替 |
| 研发资本化率 | 年报附注「开发支出」「研发投入」 | 拿不到时降级为定性，勿编造比例 |
| 关联交易明细 | 年报附注 / 临时公告 | 至少拿到关联交易总额与占比 |
| 交易所问询函 | `notice list --type 6/7` 筛，或上交所 / 深交所官网 | 部分公司披露不完整 |
| 实控人穿透 / 一致行动人 | `shareholder` + 权益变动公告 | 民企尤其要查 |
| 股权激励行权条件 | 激励计划公告 | 判断目标是否有挑战性 |

**B 类规则**：抓不到就写「目前无法可靠验证」，并在数据账本里标状态。**不得因 B 类缺失而降级整体结论，但必须在"假设与缺口"章节披露它对哪个判断的影响最大。**

---

## C 类 · 只能定性或推断

必须标注**来源口径**（哪家研报、什么时点、什么假设），禁止给出伪精确数字。

| 研究需求 | 推断路径 |
|---|---|
| 产能 / 产能利用率 / 单位成本 | `report detail` + 行业经营数据 + `finance` 的固定资产与折旧 |
| ASP 与价格趋势 | 行业经营数据 + 研报 + 收入/销量反推 |
| 市占率 / CR3 / CR5 | 研报口径 + 行业规模反推；**不同来源口径常冲突，必须并列写** |
| TAM / SAM / SOM | 研报推断；**管理层宣称的"万亿市场"一律打折并标注** |
| 订单、客户名单 | 一般不完整披露，只用已公告部分 |
| 管理层口头指引 | 业绩说明会纪要（如有）；无则标缺口 |
| 个股历史 PE / PB 分位 | **自算**：`kline` 历史价 × 总股本 ÷ 当期净利润；**禁止引用来源不明的历史分位数** |

## 算 · 推导量（报告中必须列出输入量与公式）

禁止只给结果。每一项都要能在报告中被复核。

| 指标 | 公式 / 输入 |
|---|---|
| CFO / 净利 | 5 年逐年 `cashflow` 经营活动净额 ÷ 归母净利 |
| 政府补助 / 净利 | 其他收益或营业外收入中的政府补助 ÷ 归母净利 |
| 非经常性损益占比 | （归母净利 − 扣非净利）÷ 归母净利 |
| 应收增速 vs 收入增速 | 对比两个增长率；补 DSO = 应收账款 × 365 ÷ 营业收入 |
| 存货周转天数 | 平均存货 × 365 ÷ 营业成本 |
| 商誉 / 净资产 | 商誉 ÷ 归母净资产 |
| ROIC | NOPAT ÷ 投入资本（有息负债 + 权益 − 超额现金） |
| FCF | CFO − Capex |
| 净负债 | 有息负债 − 货币资金 − 交易性金融资产 |
| 利息保障倍数 | EBIT ÷ 利息费用 |
| Reverse DCF 隐含增长 | 以当前市值为锚，反解使 DCF 等于市值的收入/利润 CAGR |
| 概率加权公允价值 | Bear×P + Base×P + Bull×P（P 之和 = 100%） |
| Margin of Safety | 1 − 当前价 ÷ 公允价值 |

> 骨架阶段：计算在报告内展开公式与中间量。后续迭代可考虑抽出可复算脚本，避免自然语言算错。

```
| 数据项 | 分档 | 来源命令 | 数据日期 | 状态 |
|---|---|---|---|---|
| 5 年三大报表 | A | finance <code> --num 20 | 2026-08-30 | 已取 |
| 股权质押比例 | A | risk <code> --types pledge | 2026-08-30 | 已取 |
| 商誉明细 | B | notice detail <年报ID> | — | 未取到，用总额替代 |

```

## 数据冲突处理

不同来源给出不同数字时，**并列写出并说明采用哪个、为什么**：

> 来源 A（`finance`）显示 2025 年营收 12.3 亿，来源 B（`report detail` 某券商研报）显示 12.8 亿。采用 A（交易所披露口径），B 的差异可能来自是否含其他业务收入。

禁止静默挑选支持自己结论的数字。
