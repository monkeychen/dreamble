# 红旗系统与早停清单

**红旗 ≠ 造假结论。** 命中红旗的含义是「这项需要解释」。给出合理解释（行业特性、一次性事件、会计口径差异）即可解除；解释不了才扣分。

---

## 一、致命红旗 · 早停清单

Stage 1 结束前逐条检查。**触发任一条 → 输出「回避」简报并停止**，不进入 Stage 2。

| # | 红旗 | 阈值 | 取数 |
|---:|---|---|---|
| F1 | 审计意见非标 | 近 2 年出现保留 / 无法表示 / 否定意见 | `notice detail` 年报（B 类） |
| F2 | 立案调查或行政处罚 | 近 3 年证监会立案调查、行政处罚 | `risk` + `notice list --type 6` |
| F3 | 实控人风险 | 失联 / 被采取强制措施 / 股权被司法冻结 | `notice list --type 4/5/6` |
| F4 | 现金流长期背离 | **CFO / 归母净利 连续 3 年 < 0.5** | `finance --num 20`（A 类，直接算） |
| F5 | 质押失控 | 控股股东质押比例 > **70%** | `risk --types pledge` |
| F6 | 商誉悬顶 | 商誉 / 净资产 > **40%** | `finance --type balance` |
| F7 | 退市风险 | ST / *ST / 退市风险警示 | `profile` / 证券简称 |
| F8 | 资金占用嫌疑 | （其他应收款 + 预付款）/ 净资产 > **15%** 且无合理解释 | `finance --type balance` |

### 行业例外（避免误杀）

- **F4 不适用于银行、保险、券商、地产**：其经营性现金流受存贷款、准备金、预售款驱动，天然大幅波动，须改看核心指标（NIM/拨备、NBV、预售回款）再判断。
- **F6 对以并购为主要成长路径的公司**（如部分医药、软件）阈值可放宽至 50%，但必须在报告中说明放宽理由。
- **F8 对工程建筑类企业**需扣除正常保证金、备用金后再判断。

命中行业例外时，**不自动早停**，改为在报告中单列「需重点解释项」。

## 二、早停简报模板

触发致命红旗时输出这个，然后停止：

```markdown
# 研究终止 · 回避

**公司 / 代码：** xxx
**数据日期：** YYYY-MM-DD

## 触发条款
- **F4 · 现金流长期背离**：2023/2024/2025 年 CFO/归母净利 分别为 0.31 / 0.28 / 0.22（来源：finance --num 20）
- **F5 · 质押失控**：控股股东质押比例 78%（来源：risk --types pledge，YYYY-MM-DD）

## 已核验
- 5 年三大报表、股东结构、质押与解禁、公告清单已拉取
- 未执行：分部盈利、估值、多空辩论（已终止）

## 为什么直接回避
<2-3 句，说明这两条叠加意味着什么>

## 重新评估条件
- CFO/净利 回升至 0.8 以上且连续 2 期
- 质押比例降至 50% 以下
- 或出现明确的基本面拐点证据（列出可观测指标）
```

## 三、会计红旗系统（17 项）

未触发致命红旗时逐项检查，用于 Stage 2 的第 14 项（会计质量评分）。

### 严重项（每项 −1.5 分）

| # | 检查项 | 判据 |
|---:|---|---|
| A1 | 应收增速 > 收入增速 | 连续 2 年以上，且差距 > 10pct |
| A3 | CFO 长期 < 净利 | 3 年及以上 CFO/净利 < 1 |
| A6 | 非经常性损益占比过高 | （归母 − 扣非）/ 归母 > 20% |
| A7 | 政府补助依赖 | 政府补助 / 净利 > 30% |
| A10 | 关联交易占比异常 | 关联销售或采购 / 营收 > 20% |
| A11 | 大额其他应收款 | 其他应收款 / 净资产 > 10% |
| A12 | 毛利率异常高于同行 | 高出可比公司均值 10pct 以上且无成本优势解释 |
| A16 | 监管问询频繁 | 5 年内 3 次以上，或同一问题被反复问询 |

### 一般项（每项 −0.5 分）

| # | 检查项 | 判据 |
|---:|---|---|
| A2 | 存货增速 > 收入增速 | 连续 2 年以上 |
| A4 | 商誉偏高 | 商誉 / 净资产 在 30%–40% 区间 |
| A5 | 研发资本化异常 | 资本化率 > 30%，或 > 同行均值 1.5 倍 |
| A8 | 频繁资产处置收益 | 3 年内 2 次以上大额处置贡献利润 |
| A9 | 频繁并购 | 3 年内 3 次以上 |
| A13 | Q4 收入异常集中 | Q4 占全年收入 > 40% 且非行业季节性 |
| A14 | 审计师频繁更换 | 5 年内更换 2 次以上 |
| A15 | 审计意见带强调事项段 | 连续出现 |
| A17 | 募投项目频繁变更 | 3 年内变更 2 次以上 |

### 评分

- 起点 10 分，按上表扣分，最低 0 分
- **Accounting Quality**：0–10
- **Fraud / Accounting Risk**：≥7 低 ｜ 4–6.5 中 ｜ <4 高

**每一项命中都必须在报告中写明：命中依据（数字 + 来源）、公司的解释、我们是否接受该解释。**

## 四、治理红旗

用于 Stage 2 第 15 项（Shareholder Alignment 评分）。

| 检查项 | 判据 | 取数 |
|---|---|---|
| 实控人质押 | > 50% 警戒，> 70% 致命 | `risk --types pledge` |
| 大股东净减持 | 过去 3 年净减持 > 3% 股本 | `notice list --type 4` |
| 言行不一 | 管理层公开看多但实际持续减持 | 公告 + 研报纪要 |
| 对外担保 | 担保余额 / 净资产 > 30% | 年报 / `notice list --type 5` |
| 同业关联体 | 实控人旗下关联公司与上市公司业务重叠 | `shareholder` + 公告 |
| 高溢价关联收购 | 收购关联方资产评估增值率 > 300% | 公告 |
| 资金占用形态 | 高现金 + 高有息负债 + 低分红（"存贷双高"） | `finance --type balance` |
| 分红长期缺失 | 连续 5 年盈利但分红率 < 10% 且无合理资本开支计划 | `dividend list --years 5` |

**Shareholder Alignment：0–10**（10 = 大股东与中小股东利益高度一致）

## 五、限售解禁与减持压力

| 窗口 | 关注 | 取数 |
|---|---|---|
| 3 个月 / 6 个月 / 12 个月 / 24 个月 | 解禁规模、占流通股比例、解禁股东成本、减持意愿 | `risk --types unlock` |

判断要点：

- 解禁规模 / 当前流通股 > 30% 属重大压力
- 定增参与者浮盈 > 50% 时减持意愿显著上升
- 控股股东解禁通常压力小于财务投资者解禁
