# A股 / 港股买方深度研究

**核心命题**：好公司 ≠ 好股票。唯一要回答的问题是——

> 当前价格隐含了怎样的未来？未来真实结果与市场隐含预期之间，是否存在足够大的差异？

产出的是**决策底稿**，不是研报。内部研究结构（红旗清单、证据账本、反方论证、证伪条件）必须保留在正文里，不改写成人话散文。

---

## 适用范围与边界

| | 本 skill | `securities-analyst` |
|---|---|---|
| 视角 | 买方投委会 | 卖方研究 |
| 产物 | 决策底稿，**保留**内部研究结构（红旗清单、反方论证、证伪条件） | 可直接发布的文章，**不展示**内部研究标题 |
| 篇幅 | 决策页 ≤3 页 + 尽调附录 | 面向读者的完整长文 |
| 典型请求 | 判断错误定价、算买入区间、排查财务与治理风险 | 写一篇能发的文章、快速点评、行业梳理 |

**路由规则**：两个 skill 触发词高度重叠（都含"分析某只股票""值不值得买""目标价"）。区别不在标的，在**产物形态**——用户要"能发出去的文章"就走 `securities-analyst`，要"自己拿去下注的判断"就走本 skill。

同一家公司两个都可以跑，数据都走 westockdata，但**不要混用产物形态**：别把决策底稿当文章发，也别把卖方文章当买入依据。

## 铁律

1. **数据只走 westockdata**。命令简写 `westock-data <cmd>` = `npx -y westock-data-skillhub@1.0.5 <cmd>`。禁止 web_search / HTTP 直连 / 训练记忆补数。
2. **批量优先**。支持逗号多代码的命令只调 1 次；无依赖的多组查询在同一轮并行发出，禁止串行等结果。
3. **事实 / 推断 / 假设必须分离**，正文标注【事实】【推断】【假设】。
4. **拿不到就是拿不到**。查不到的数字写「目前无法可靠验证」，并**将该项从决策依据中剔除**——不是写进报告凑篇幅。禁止编造目标价、一致预期、管理层讲话、市占率、订单。
5. **缺失输入不询问**。投资周期缺省取 3–5 年，A+H 缺省两个市场都查。所有假设在报告"假设与缺口"章节披露，不在执行中途挂起等用户回答。
6. **早停优先于完整**。触发致命红旗立即出「回避」简报并停止，不往下跑。买方研究的价值在于止损，不在于写满 72 节。

## 四阶段流程

### Stage 0 · 输入解析（≤2 次调用）

公司名未知代码 → `westock-data search <名称>`。A+H 同时上市 → 两组代码都查，最终做 AH 比较。

### Stage 1 · 数据拉取 + 红旗快筛

**一次性并行拉取**（按市场选命令，缺哪个记进数据账本）：

```bash
westock-data kline <code> --period day --limit 5          # 价格与数据日期
westock-data finance <code> --num 20                       # 5年×4期三大报表
westock-data profile <code>                                # 公司简况
westock-data shareholder <code>                            # 十大股东/股东户数/港股机构持仓
westock-data dividend list <code> --years 5                # 分红
westock-data buyback <code>                                # 回购
westock-data report list <code> --limit 10                 # 研报列表（取ID后再 detail）
westock-data notice list <code> --type 0 --limit 30        # 公告
westock-data risk <code>                                   # 质押+解禁+违规等8类风险事件
westock-data fund north-holding <code>                     # A股北向（港股用 south-holding）
westock-data fund flow <code>                              # 资金流
```

港股追加 `westock-data fund short <code>`（做空比例）。同业对比把代码用逗号拼进 `finance` / `report list` / `fund flow` 的同一条命令。

详细命令与数据分档见 [references/data-sourcing.md](references/data-sourcing.md)。

**然后跑早停清单**（[references/red-flags.md](references/red-flags.md)）。触发任一条致命红旗 → 输出「回避」简报（触发条款 + 数据出处 + 重新评估条件）→ **停止**。

未触发 → 生成**数据可得性账本**（A 类已取 / B 类待抓原文 / C 类只能定性），带着账本进入 Stage 2。

### Stage 2 · 决策核心（20 项硬要求）

按 [references/output-templates.md](references/output-templates.md) 的表格逐项产出。**每项必须给出数据来源命令与数据日期**，没有数据的项标注缺口并剔除出决策依据。

| # | 项目 | 最低要求 |
|---:|---|---|
| 1 | 赚钱逻辑 + 单位经济模型 | 拆到决定利润的经营变量（销量×ASP / 门店×单店 / 装机×利用小时×电价 / 用户×ARPU） |
| 2 | 业务分部表 | 收入占比、利润占比、增速、毛利率、竞争力、前景 |
| 3 | 行业与竞争 | CR3/CR5、利润池、份额趋势；回答"增长来自行业还是份额" |
| 4 | 护城河评分 | 15 项各 0–10，给宽度（无/窄/中/宽/极宽）与趋势（扩大/稳定/收窄） |
| 5 | 政策环境 | 受益 / 中性 / 高风险；政策红利占利润比例 |
| 6 | 5 年财务表 | 收入、毛利、营业利润、净利、扣非、CFO、Capex、FCF、ROE、ROIC、净负债 |
| 7 | 归母 vs 扣非 | 非经常性损益占利润比；判断真实主营盈利 |
| 8 | 政府补助 | 5 年金额与 Subsidies/Net Profit |
| 9 | CFO / 净利 | 5 年比值；长期 <1 必须解释 |
| 10 | 应收 | 应收增速 vs 收入增速、DSO、客户集中度 |
| 11 | 存货 | 周转天数、结构、减值风险 |
| 12 | 商誉 | 商誉/净资产、逐项收购与减值史 |
| 13 | 研发资本化率 | 与同行对比，判断是否在美化当期利润 |
| 14 | 会计质量 | Accounting Quality 0–10 + Fraud Risk 低/中/高 |
| 15 | 实控人与治理 | 穿透、质押、关联交易、解禁、减持；Shareholder Alignment 0–10 |
| 16 | 监管与审计 | 5 年问询函/处罚/审计意见/事务所更换 |
| 17 | 管理层 | 承诺 vs 结果表；Management Quality 0–10 |
| 18 | 估值三重锚 | 历史区间（自算）+ 同行表 + **Reverse DCF** |
| 19 | 三情景 + 概率加权 | Bear/Base/Bull 各赋概率，算期望收益与 Margin of Safety |
| 20 | Variant Perception | **必须量化、可证伪**（例：市场隐含 2027–29 收入 CAGR 8%，我们判断 14–16%，依据是产能利用率 X 与份额 Y） |

**20 项之外**的章节（TAM/SAM/SOM、产能周期、可转债条款、股权激励、资本配置史、行业专属指标等）属**可选附录**：有数据就写，没数据跳过，不因缺失而降级结论。

### Stage 3 · 多空辩论

加载 [references/debate-protocol.md](references/debate-protocol.md)，依次产出：

1. **做空者审计** —— 站在顶级做空基金立场，提出**最强**空头逻辑，不是为平衡而凑的弱论点
2. **多头反驳** —— 只用数据、事实、商业逻辑逐条回应，禁止情绪化辩护
3. **投委会裁决** —— 多头最强点 / 空头最强点 / 哪些风险已反映在价格里 / 哪些没有 → Buy / Watch / Avoid
4. **Pre-Mortem** —— 假设三年后亏 50%，倒推最可能的 5 个原因，并判断**现在是否已有早期迹象**

### Stage 4 · 输出

按 [references/output-templates.md](references/output-templates.md) 的固定结构产出，分两层：

- **决策页（必交付，≤3 页）**：Investment Snapshot → 三情景与概率加权 → Kill Criteria → 季度监控 Dashboard → 极简总结
- **尽调附录（可缺）**：Stage 2 全表 + 多空辩论全文，允许大量「目前无法可靠验证」

保存到 `tmp/YYYY-MM-DD-<证券简称>-深度研究.md`，回复中给出文件链接。

## 关键判断规则

- **估值方法按公司类型选**，不机械套 PE：成长股 PE/PEG/EV-FCF，周期股 Mid-cycle PE + PB + EV/EBITDA（**先判断是否 Peak Earnings，是则禁用当期 PE**），高股息 Dividend Yield + FCF Yield，银行 PB/ROE/不良/拨备，保险 P/EV + NBV，地产 NAV，资源股 NAV/单位成本。不适用的指标舍弃并说明原因。
- **个股历史 PE 需自算**：westockdata 只给板块估值分位。用 `kline` 历史价 × 总股本 ÷ 当期净利润，不要引用来源不明的历史分位数。
- **资金流不是利好本身**：北向/南向变化要判断是原因还是结果，结合基本面解释。
- **不要把所有回购都当利好**：区分注销 / 股权激励 / 员工持股。
- **周期股必查当前是否 Peak Earnings**，是则禁用当期 PE 并改用 mid-cycle 口径。
- **A+H 必算 A/H Premium**，比较 PE、PB、股息率、流动性、投资者结构，回答"H 股折价是否提供更好风险收益比"。

## 评分与结论

最终给出 15 维评分（商业模式、护城河、行业结构、增长空间、政策环境、财务质量、会计质量、现金流、ROIC、管理层、实控人治理、资本配置、资产负债表、估值、风险收益比）与 Overall Investment Score / 100。

评级只取：**强烈买入 / 买入 / 观察 / 减持 / 回避**。

信心等级只取：**低 / 中 / 高**。信心等级低时，即使评级是买入，也必须明确写"当前证据不足以支撑重仓"。

## 失败处理

关键行情、股本或财报无法核验时，写明缺什么、已核验什么、缺口如何影响结论。可给**条件化情景与触发规则**，但禁止伪精确目标价，禁止把资料不足包装成完整研究。
