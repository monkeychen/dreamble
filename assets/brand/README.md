# 品牌资产目录

本目录存放「聊哉梦呓」跨渠道使用的品牌源文件和渠道成品，不属于任何单个子项目的运行资源。

## 结构

- `wechat/`：微信公众号头像等微信渠道资产。
- `x/`：X（Twitter）头像、个人主页背景等渠道资产。
- 后续新增渠道时使用小写英文目录名，例如 `website/`、`social/`。

## 命名

- `*-master.*`：保留尺寸和质量的母版。
- `*-upload.*`：按对应平台要求处理、可直接上传的成品。
- 同一资产需要迭代时追加版本号，例如 `avatar-master-v2.png`，不要覆盖仍在使用的版本。

## 清理

- 已废弃且不再被任何渠道使用的成品可以删除。
- 母版只在确认有更新版本并完成渠道替换后删除。
- 网站实际需要公开访问的文件，按需复制到 `site/public/`；不要把仅供人工上传的渠道资产放入站点目录。
